# Axel Rolón — Astro Portfolio

## Run locally

```bash
npm install
npm run dev
```

Then open the local Astro development URL.

## Build

```bash
npm run build
npm run preview
```

## Customize

- `src/data/resume.ts` contains the resume and project data.
- `src/pages/index.astro` contains the page structure.
- `src/styles/global.css` contains all visual styling.
- Replace the `AX` portrait placeholder in `index.astro` with a real photo when ready.
- Replace the `#` project URLs in `resume.ts` with real GitHub/live-demo URLs.

The site intentionally uses no animation library and no UI framework, keeping the initial implementation lightweight.
